# How to Contribute

## For Passers-by
If you're just passing by and want to learn more about our hall, feel free to explore the site!
However, we are not currently accepting contributions from the general public. If you are affiliated with 5W, please see the next section.

## For 5W Residents
If you are a resident of 5W (past or present) and want to contribute to the website, there are several ways you can do so:
1. **Content Contributions**: If you have content (text, images, etc.) that you would like to add to the website, please reach out to the TechComm. We will review your content and, if appropriate, add it to the website.
2. **Code Contributions**: If you are interested in contributing code to the website, please follow the steps in [README.md](README.md) to set up the project and submit a pull request.

## For TechComm Members
If you are a member of the TechComm and want to contribute to the website, please follow the steps in [README.md](README.md) to set up the project.
Please also contact davidbartus on Discord to be added to this repository as an administrator.
